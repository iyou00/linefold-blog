# 产品与信息架构

## 产品目标

LINEFOLD 用来持续记录项目过程、日常感受和可复用教程。读者进入首页后可以直接看到最新内容，作者可以通过简单后台完成发布与维护。

## 前台栏目

| 栏目 | 地址 | 内容 |
| --- | --- | --- |
| INDEX | `/` | 最新文章，第一篇放大，其余列表展示 |
| NOTES | `/notes` | 日常感受、观察、读书笔记与项目过程 |
| TUTORIALS | `/tutorials` | 教程、方法和可复用实践 |
| ARCHIVE | `/archive` | 全部文章按年份和日期排列 |
| ABOUT | `/about` | 个人介绍、更新方式和联系方式 |

项目内容使用 `PROJECT` 标签进入随笔，成熟作品数量增加后可以扩展独立 `PROJECTS` 页面。

## 后台流程

1. 访问 `/admin/login`。
2. 输入后台账号密码。
3. 新建或选择文章。
4. 填写标题、摘要、Markdown 正文、分类、标签与图片外链。
5. 使用草稿状态保存，完成后切换为发布。
6. 首页依据发布时间自动更新顺序。

## 内容模型

文章包含：标题、路径、摘要、正文、分类、标签、图片外链、状态、发布时间、SEO 标题和 SEO 描述。首页标题、介绍和关于文案作为站点设置单独管理。
