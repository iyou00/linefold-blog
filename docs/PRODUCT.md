# 产品与信息架构

## 产品目标

LINEFOLD 用来持续记录项目过程、日常感受和可复用教程。读者进入首页后可以直接看到最新内容，作者可以通过简单后台完成发布与维护。

## 前台栏目

| 栏目 | 地址 | 内容 |
| --- | --- | --- |
| INDEX | `/` | 最新文章，第一篇放大，其余列表展示 |
| WRITING | `/writing` | 全部文字记录，可筛选随笔与教程 |
| WORKS | `/works` | 作品索引、LINEFOLD 概念构图与 CASE 详情 |
| ARCHIVE | `/archive` | 全部文章按年份和日期排列 |
| ABOUT | `/about` | IDENTITY、NOW 与 COORDINATES 三段个人档案 |

旧地址 `/notes` 与 `/tutorials` 会跳转到 WRITING 的对应筛选状态。

## 后台流程

1. 访问 `/admin/login`。
2. 输入后台账号密码。
3. 新建或选择文章。
4. 填写标题、摘要、Markdown 正文、分类、标签与图片外链。
5. 使用草稿状态保存，完成后切换为发布。
6. 首页依据发布时间自动更新顺序。

作品通过后台“作品管理”独立维护。CASE 包含作品名称、简介、发布时间、自定义 HTTPS 链接、可选图片组和最多三篇关联文章。图片组开启且没有外链图片时，前台使用两张内置 LINEFOLD 概念示意图；关闭时完整隐藏图片区。

文章详情与 CASE 详情的右栏先展示共享评论流，再提供匿名留言框。访客无需注册即可提交纯文本留言；前台固定显示最新五条，并用第六条渐隐表达评论仍在继续。留言卡片省略重复署名，以日期、正文和渐变便签区分层次。菜单页右栏专注视觉识别与全局信息，页面切换保持稳定。

## 内容模型

文章包含：标题、路径、摘要、正文、分类、标签、图片外链、状态、发布时间、SEO 标题和 SEO 描述。首页标题、介绍和关于文案作为站点设置单独管理。

作品包含：名称、路径、简介、标签、状态、发布时间、自定义链接、图片显示开关和有序图片列表。作品与文章通过关联表连接，删除作品不会删除文章。

评论包含：匿名署名、纯文本内容、来源页面、审核状态、IP 哈希、创建时间和更新时间。文章详情与 CASE 详情读取同一条全局时间流。
