# 视觉与响应式规范

## 视觉语言

- 纸张底色：`#FAFAF8`
- 抬升内容面：`#FDFDFB`
- 柔和内容面：`#F2F0EA`
- 辅助实体色块：`#E9E7E0`
- 主文字：`#171717`
- 辅助文字：`#7D7D7A`
- 分割线：`#DEDED8`
- 唯一强调色：`#6257DD`
- 中文标题：系统宋体栈
- 中文正文：系统黑体栈
- 导航与日期：系统等宽字体栈

全部字体由访客操作系统提供，页面不会请求境外字体服务。

## 大屏比例

- 页面最大宽度：`1480px`
- 页面外边距：`40–112px` 自适应
- 左栏：`220px`
- 中栏：`700–840px`
- 右栏：`280–420px`，吸收剩余空间
- 文章正文最大宽度：`720px`
- 桌面主标题：`46–64px`
- 正文：`17–18px / 1.75–1.9`
- 桌面端整张三栏框架固定在视口内，只有中栏承担垂直滚动。
- 上下左右四条边界始终可见，左侧导航与右侧视觉栏保持完全静止。

## 手机端

`720px` 以下进入单栏：左侧栏替换为顶部菜单，左右内边距 `24px`，右侧线稿隐藏，首页最新文章保持放大层级，后续文章改为纵向列表。

## 交互原则

- 导航、标题和文字链接提供键盘焦点状态。
- 内容区域保持稳定，不使用自动动画。
- 留白、浅色内容面、实体几何和文字比例共同承担层级。
- 强调色用于当前栏目、状态、路径和少量几何节点。
- 桌面端的邮箱与备案信息位于右栏底部，使用小号等宽字体与低对比度文字。
- `1240px` 以下右栏隐藏时，必要的页脚信息自动回到内容末尾。
- 系统启用减少动态效果时，页面关闭平滑滚动。

## 右侧几何系统

- 首页使用基础构成线稿，作为整套视觉语言的母版。
- 随笔页使用轨道构图，教程页使用堆叠构图，归档页使用时间轴构图。
- 文章详情页提供轨道、堆叠、时间轴、折线与信号五种变体，由文章 slug 稳定选择。
- About 页面固定使用可随作者名称变化的字母签名、`作者 / LINEFOLD` 档案标识、时间刻度与个人坐标感的专属构图。
- 视觉风格定义为 `Paper Axonometric / 纸上轴测`：正面使用纸张色，顶面保留暖白，侧面使用淡紫色。
- 每个构图由一个低透明度轴测方块、两个轮廓形状、一条路径和少量节点组成。
- 所有图形均由本地 CSS 构成，透明度保持在 `0.16–0.22`，实体色块使用暖灰或淡紫。
- `1240px` 以下隐藏右栏，让阅读宽度与移动端性能保持稳定。
