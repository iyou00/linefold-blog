# 后台使用

## 工作台结构

- 后台左栏固定显示“文章管理”和“站点设置”两个一级入口。
- 文章管理下方显示搜索、筛选、新建和文章列表；右侧工作区负责正文编辑、实时预览和发布检查。
- 站点设置下方显示品牌信息、首页与 About、右栏与联系、社交入口、备案与合规五个分类；右侧工作区只显示当前分类。
- 正文区域在桌面端默认显示编辑与实时预览左右分栏，发布检查栏位于最右侧。
- 正文工具栏提供二/三级标题、加粗、删除线、列表、引用、代码块和链接快捷插入，并实时显示字数与预计阅读时间。
- 编辑器使用 CodeMirror 6，支持 Markdown 语法高亮、撤销重做、搜索、智能续写列表、行号与 `Ctrl/Cmd + B`、`Ctrl/Cmd + I` 快捷键。
- 顶部会显示未保存状态，并分别提供保存草稿和发布文章操作。
- 站点设置切换分类时保留当前修改，离开模块或退出后台时提示未保存状态。

## 修改左栏标题

进入“站点设置 → 品牌与身份”，修改“网站名称”和“左栏简称”。同一区域可以管理作者称呼、网站描述、联系邮箱和开始记录年份。

## 登录

后台入口为 `/admin/login`。初始凭据保存在本地 `CREDENTIALS.local.md`，生产部署完成后立即更换密码哈希和会话密钥。

## 发布文章

- 标题：读者看到的文章标题。
- 文章路径：英文、数字和连字符组成；留空时自动生成。
- 分类：随笔或教程。
- 状态：草稿只在后台显示，发布后进入前台。
- Markdown 正文：支持 CommonMark 与 GFM，包括标题、段落、嵌套/有序列表、引用、代码、链接、图片、表格、任务列表和删除线。
- 封面图片外链：用于文章标题下方的大图与社交分享卡片，每篇文章一张。
- 正文图片：在“图片与展示”中填写图片地址和说明，点击“插入到当前正文位置”；重复操作即可插入任意数量。
- 图片安全：封面和正文图片都只接受 HTTPS 与国内资源白名单域名。
- 原始 HTML：编辑器保留输入文本，预览和前台会丢弃 HTML 标签及其内容。
- 标签：使用英文逗号分隔，项目内容可以添加 `PROJECT`。
- SEO：留空时自动使用文章标题和摘要；编辑器提供字数提示与搜索结果预览。

发布后的文章会自动生成规范链接、Open Graph、分享卡片信息、文章时间、作者、标签和 `BlogPosting` 结构化数据。生产环境需要正确设置 `SITE_URL`，站点地图才能输出正式域名。

## 社交入口与备案

- “站点设置 → 外部入口”最多配置四个平台，显示在左栏 `SINCE` 下方。
- “站点设置 → 备案信息”管理 ICP 备案号、公安备案号和公安备案查询链接。
- ICP 备案号自动链接到工信部备案系统，所有备案信息显示在全站内容页脚。
- “站点设置 → 右栏信息”管理 EMAIL 的显示状态、联系邮箱及版权文字。

## 长期文章管理

- 后台文章列表每次读取 30 条元数据，完整正文在点击文章后单独读取。
- 搜索与状态筛选由数据库执行，搜索词最长 100 个字符。
- “加载更多”使用更新时间与文章 ID 组成的游标，持续写作多年后仍保持稳定查询。

## 首页顺序

已发布文章依据发布时间倒序排列。第一篇自动进入首页放大区域，后续文章进入列表。

## 数据备份

SQLite 模式定期备份 `data/field-notes.sqlite`。备份前可以短暂停止写入，或使用 SQLite 在线备份工具生成一致副本。
